# SpendWise Budget Calculator

A beginner-friendly JavaScript budget calculator created for the PLP Week 5 assignment.

## Project purpose
SpendWise helps a user enter their monthly budget and expenses, then calculates the money remaining.

## Files
- `index.html` – page structure and calculator button.
- `style.css` – page styling and responsive layout.
- `script.js` – prompts, calculations, reusable functions, and console output.

## JavaScript concepts used
- Variables (`const` and `let`)
- Numbers and strings
- Functions and function parameters
- Arithmetic operators
- `prompt()` for user input
- `console.log()` for labelled results
- Event listeners

## How to run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser (or use the VS Code Live Server extension).
4. Click **Calculate my budget**.
5. Enter your monthly budget, then enter each expense when prompted.
6. Open the browser developer tools with **F12** and select the **Console** tab to view the results.

## Example
If the budget is KSh 40,000 and expenses are KSh 12,000, KSh 5,000 and KSh 3,000, the remaining balance is KSh 20,000.
